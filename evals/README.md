# 시험 시나리오 명세

[design-cases.json](design-cases.json)은 제품 개발 단계에서 실행할 시나리오입니다. 현재 상태는 전부 `not_run`입니다. 실제 시험 구현과 결과가 생기기 전 pass로 표시하지 않습니다.

[평가 설계](../docs/08_TEST_AND_EVALUATION.md)의 기능·안전·검색·호스트 matrix를 함께 읽으세요. 계약 초안의 JSON Schema 검사는 제품의 OAuth·MCP·DB·삭제 보증을 대신하지 않습니다.

## v2 추가 사례

`v2-design-cases.json`은 FR-15~20의 제품 수용 시험 24건입니다. 기존 37건과 중복되지 않는 ID를 사용하며 모두 not_run입니다. 참조 실험 시험과 혼동하지 않습니다. 실제 작업 benchmark의 독립 사례 수와도 다른 수치입니다.
