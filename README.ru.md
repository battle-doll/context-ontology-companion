# Context Ontology Companion

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

**Предварительная версия P1a · [Текущий статус публикации и проверок](release-state.json)**

Восстанавливайте явно переданные решения, цели и ограничения проекта вместе с источниками и историей изменений. Context Ontology Companion разрабатывается как самостоятельный публичный плагин.

`demo` использует синтетические примеры, временное хранилище и имитацию одобрения. Отдельный локальный прототип уже реализует постоянное локальное хранение, проверку человеком с аутентификацией через loopback и вручную настраиваемый stdio. Локальные синтетические тесты пройдены. В macOS с Codex 0.153.3 также пройдена базовая проверка вручную настроенного локального stdio на явно помеченных тестовых примерах. Установка из публичного маркетплейса GitHub и базовая проверка установленного исполняемого кода также пройдены в macOS. Интеграция с размещённым ChatGPT и настоящее одобрение человеком не проверены; отдельная заявка в universal Directory пока не подана. Работа с реальными данными и аутентификация в промышленной эксплуатации пока не поддерживаются.

[Локальная программа и проверка с аутентификацией (английский)](docs/LOCAL_RUNTIME.md)

Локальная проверка с аутентификацией и вручную настраиваемый stdio остаются предварительной версией. Базовая проверка Codex в macOS использовала имитацию одобрения и не подтверждает процесс проверки человеком. Используйте только синтетические данные. Защита Windows ACL не проверена.

## Установка публичной предварительной версии

Публичная предварительная версия уже доступна. Установите полный пакет через Codex CLI с поддержкой плагинов:

```sh
codex plugin marketplace add battle-doll/context-ontology-companion
codex plugin add context-ontology-companion@context-ontology-preview
```

В новой задаче Codex вызовите `$manage-approved-context` и попросите запустить синтетическую демонстрацию установленного пакета. Сохраняйте весь пакет: одного `SKILL.md` недостаточно без исполняемого кода, примеров и включённых контрактов. Постоянное хранилище и проверка человеком настраиваются отдельно от этой демонстрации.

[Быстрый старт для Windows](docs/WINDOWS_QUICKSTART.md) · [Текущий статус выпуска](release-state.json). Установка из маркетплейса GitHub и публикация в universal Directory — разные статусы. Приведённые ниже результаты CI относятся к завершённому запуску по ссылке; последующие результаты публикации и тестов ОС смотрите в файле состояния выпуска.

## Запуск локальной версии

В каталоге этого репозитория используйте Python 3.11 или новее. Для демонстрационных команд дополнительные пакеты Python не нужны. Виртуальное окружение и команды Windows описаны в руководстве по ОС.

```sh
python3 --version
python3 scripts/run.py demo
python3 scripts/run.py tools
python3 scripts/check.py
```

Команды запускают локальный код разработки. Они не устанавливают плагин и не создают размещённый сервис. Все примеры синтетические.

## Границы продуктов

Code, Context и Contracts — независимые продукты. Потребители могут закреплять или включать контрактные артефакты без установки плагина Contracts. Это не означает общую БД, наследование прав, автоматический вызов другого плагина или изменение существующего Code.

В демонстрации и локальном прототипе проверки используйте только синтетические данные. Сохранённый текст и флаги одобрения от модели не разрешают текущее действие. Локальный адаптер доверяет учётной записи ОС и администратору; он не изолирует одобрение от процесса с таким же неограниченным доступом к файлам. Историческое восстановление `known_at` не поддерживается.
