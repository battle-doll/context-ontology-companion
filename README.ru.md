# Context Ontology Companion

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

Сохраняйте выбранные решения, требования и ограничения проекта локально, а затем находите их вместе с источниками и историей изменений. Записи можно обновлять, отзывать, удалять и экспортировать для других инструментов.

Работает на macOS, Windows и Linux с Python 3.11 или новее. Ключ API и удалённый сервис не нужны.

## Установка

```text
codex plugin marketplace add battle-doll/context-ontology-companion
codex plugin add context-ontology-companion@context-ontology-preview
```

Устанавливайте плагин целиком, чтобы навык, сервер и схемы оставались совместимыми.

## Подключение проекта

Откройте нужный проект в Codex и отправьте:

```text
$manage-approved-context
Настрой локальное MCP-подключение этого плагина для текущего проекта.
```

После настройки откройте новую задачу в том же проекте для доступа к MCP-инструментам. Команды для ручной настройки, расположение установленного плагина и инструкции для разных ОС описаны в [руководстве по локальному MCP](docs/LOCAL_MCP.md) и [быстром старте для Windows](docs/WINDOWS_QUICKSTART.md).

## Использование

Укажите конкретное решение для сохранения:

```text
$manage-approved-context
Сохрани требование проекта: поддерживать macOS, Windows и Linux.
Используй это сообщение как источник.
```

В следующей задаче его можно найти:

```text
$manage-approved-context
Найди поддерживаемые операционные системы этого проекта и покажи источники.
```

Также можно попросить изменить или удалить выбранную запись, показать её историю или экспортировать контекст. Команды CLI для работы без MCP приведены в [руководстве по локальному использованию](docs/LOCAL_USE.md).

Данные хранятся вне репозитория под локальной учётной записью ОС и разделяются по пути проекта. Сохраняется только выбранное содержимое; разговоры целиком автоматически не собираются. Сохранённые решения служат контекстом и не дают разрешения на последующие действия. Не сохраняйте учётные данные и чувствительные персональные сведения. Для работы из облачного хоста нужно отдельно подключить локальную среду выполнения.

## Обновление

```text
codex plugin marketplace upgrade context-ontology-preview
codex plugin add context-ontology-companion@context-ontology-preview
```

После обновления повторите запрос на подключение проекта и откройте новую задачу, чтобы использовать новую установленную версию.
