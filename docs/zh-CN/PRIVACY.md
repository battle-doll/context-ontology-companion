# Context Ontology Companion — 隐私

当前预览仅使用合成数据。不要把真实会话、凭据、个人记录或私有源码放入示例、日志或 Issue。本地核心不依赖遥测或外部模型补充。粘贴到宿主的信息仍受宿主自己的处理规则约束。本地删除不承诺擦除宿主历史、备份或此前导出的文件。

`demo` 使用合成示例、临时存储和模拟批准。另一个本地原型已实现持久本地存储、经过认证的回环人工审核页面，以及手动配置的 stdio。本地合成测试已通过；真实数据使用、生产认证和实际 ChatGPT/Codex 宿主集成仍不受支持。

[详细政策（英文）](../../PRIVACY.md) · [文档索引](README.md)

Proposal 的批准有效期为15分钟，过期不等于自动从磁盘删除。Payload 清理在审核服务器运行时每30秒执行一次，或由操作员明确运行 `purge-expired`。准备变更草案不会执行此清理。服务器和维护任务停止时，过期 payload 会保留在磁盘上，直到清理运行。
