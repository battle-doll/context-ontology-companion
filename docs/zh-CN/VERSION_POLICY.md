# Context Ontology Companion — 版本政策

设计版本不是运行时或插件版本。区分 schema/profile、validator 和消费者版本，固定受支持产物及 digest。兼容性需要明确的 producer→consumer 组合和已执行 fixtures，不能仅凭版本号推断。保留历史草案并拒绝不支持的版本。

`demo` 使用合成示例、临时存储和模拟批准。另一个本地原型已实现持久本地存储、经过认证的回环人工审核页面，以及手动配置的 stdio。本地合成测试已通过；真实数据使用、生产认证和实际 ChatGPT/Codex 宿主集成仍不受支持。
