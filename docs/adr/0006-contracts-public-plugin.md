# ADR 0006 — Contracts 배포물과 공개 플러그인 분리

상태: 사용자 공개 목표 반영; 구현 방식은 P0/P1 검증 대상.

사용자는 Contracts도 별도 공개 플러그인으로 요청했습니다. 한 저장소에 버전별 데이터 계약/fixtures/검증기와 사용자-facing 검증 skill을 둘 수 있지만 서로 다른 산출물·버전·완료 상태로 관리합니다. 소비자 제품은 검증 plugin을 설치하지 않고 계약 artifact를 사용합니다.

장점은 독립 사용자 가치와 기존 제품의 설치 단순성입니다. 비용은 별도 README/지원/시험/등록 관리입니다. 부모 플러그인의 권한이나 DB를 공유하는 구조는 채택하지 않습니다. 공통 순수 core는 별도 실재하는 재사용 근거가 있을 때만 추출합니다.
