# ADR-0004 — 이력 무결성과 본문 삭제 분리

날짜: 2026-08-29

상태: **Proposed**

## 배경

감사 가능한 기억과 사용자 삭제 통제를 동시에 충족해야 합니다.

## 결정

대체/철회 이력은 보존 정책 안에서 유지하되 erase는 원문과 파생물을 제거합니다.

## 결과와 대안

본문과 감사 메타데이터를 분리하고 backup restore에 deletion replay를 적용합니다. soft delete만으로 forget 완료라고 말하지 않습니다.

## 변경 규칙

새 근거가 나오면 기존 문서를 지우지 말고 대체 ADR과 이유·영향·승인 상태를 기록합니다.
