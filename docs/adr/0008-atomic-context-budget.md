# ADR 0008 — 필수 문맥·충돌·근거의 원자적 예산 처리

상태: 제품 불변식; 참조 실험 일부 수행.

예산이 작을 때 중요한 제약 또는 충돌 한쪽만 누락하는 요약은 잘못된 행동을 유발할 수 있습니다. 필수 그룹과 그룹별 근거를 원자적으로 다룹니다. 필수 합이 예산을 넘으면 명시적으로 실패/범위 축소하고, 선택 그룹 누락은 커버리지에 표시합니다.

이는 모든 문맥을 무손실로 기억하는 보장이 아닙니다. 필수 집합의 발견, 권한, 유효시점은 별도 upstream 책임입니다. 참조 실험의 성공을 검색/보안 성공으로 확대하지 않습니다.
