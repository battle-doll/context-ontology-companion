# ADR-0003 — 명시적 최소 문맥과 사용자 승인

날짜: 2026-08-29

상태: **Proposed; platform/data boundaries mandatory**

## 배경

출처 확인·프라이버시·승인 오염을 관리해야 하며 공개 지침상 전체 채팅 수집/복원을 지원하지 않습니다.

## 결정

전체 대화 수집 대신 목적별 최소 후보를 받고 검증 가능한 사용자 승인 후 지식으로 활성화합니다.

## 결과와 대안

편의성보다 명시적 통제를 우선합니다. 호스트 승인을 서버가 검증할 수 없다면 자체 인증 검토 UI를 사용합니다. 상세 근거는 docs/13_SOURCES_AND_VERIFICATION.md의 S-02에 있습니다.

## 변경 규칙

새 근거가 나오면 기존 문서를 지우지 말고 대체 ADR과 이유·영향·승인 상태를 기록합니다.
