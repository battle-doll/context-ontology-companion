# ADR-0001 — 별도 플러그인

날짜: 2026-08-29

상태: **Accepted — 사용자 명시적 채택**

## 배경

코드 분석과 사용자 문맥 관리의 가치·데이터·권한·운영 경계가 다릅니다.

## 결정

Code와 Context를 별도 제품으로 유지하고 공통 계약·적절한 코어만 공유합니다.

## 결과와 대안

기존 코드 도구의 신뢰 경계를 유지합니다. 제품/테스트/운영 관리는 각각 필요합니다. 하나의 대형 플러그인 또는 관련 없는 독립 구현은 선택하지 않습니다.

## 변경 규칙

새 근거가 나오면 기존 문서를 지우지 말고 대체 ADR과 이유·영향·승인 상태를 기록합니다.
