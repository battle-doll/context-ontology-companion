# ADR-0005 — 공통 코어는 순수 코드

날짜: 2026-08-29

상태: **Proposed**

## 배경

공통화가 기존 local-first/결정론적 경계를 무너뜨려서는 안 됩니다.

## 결정

코어에는 검증·정규화·관계·시간 같은 순수 함수만 두고 IO·OAuth·LLM·DB를 두지 않습니다.

## 결과와 대안

두 제품은 공통 계약을 통해 독립적으로 작동합니다. runtime 공유의 비용이 이득보다 크면 계약 공유만 유지하며 ADR을 수정합니다.

## 변경 규칙

새 근거가 나오면 기존 문서를 지우지 말고 대체 ADR과 이유·영향·승인 상태를 기록합니다.
