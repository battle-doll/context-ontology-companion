# Context Ontology Companion — リリースとロールバック

設計・契約成果物・ランタイム・ホスト連携・提出・承認・公開を別々に追跡します。一台のテスト成功は三 OS のリリース証拠ではありません。バージョンと digest を固定し、リリース証拠を保持します。公開前にライセンス権利、非公開脆弱性報告、掲げるすべての OS、実際のホスト動作を確認します。コードのロールバックにはデータと契約の互換計画が必要です。

`demo` は合成例、一時保存、模擬承認を使用します。別のローカル試作版には、永続ローカル保存、認証付きループバックの人による確認画面、手動設定する stdio を実装しました。ローカルの合成テストは成功しています。実データの利用、本番認証、実際の ChatGPT/Codex ホスト連携は未対応です。
