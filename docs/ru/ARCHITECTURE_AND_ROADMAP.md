# Context Ontology Companion — Архитектура и план

Contracts предоставляет версионируемые артефакты; каждый продукт управляет собственным процессом и правами. Context — локальный синтетический потребитель, Contracts — детерминированный автономный валидатор. Доверенное одобрение хоста, промышленное хранение, публичные плагины и дополнительный мост Code относятся к следующим этапам. Общее исполняемое ядро извлекается только после подтверждения одинаковых требований двумя реальными потребителями.

`demo` использует синтетические примеры, временное хранилище и имитацию одобрения. Отдельный локальный прототип уже реализует постоянное локальное хранение, проверку человеком с аутентификацией через loopback и вручную настраиваемый stdio. Локальные синтетические тесты пройдены. Реальные данные, промышленная аутентификация и фактическая интеграция с ChatGPT/Codex пока не поддерживаются.
