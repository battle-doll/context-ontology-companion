# Context Ontology Companion — 기여

변경은 해당 제품 범위에 한정합니다. 기존 Code 식별자와 어휘, 계약 버전 경계, 합성 fixtures, 관측 사실과 추론의 구분을 보존하세요. Python 3.11 이상에서 scripts/check.py를 실행하고 실제 실행한 명령만 보고합니다. 대기 중인 시험을 통과로 바꾸지 않습니다.

`demo`는 합성 예제·임시 저장소·모의 승인을 사용합니다. 별도의 로컬 프로토타입에는 영구 로컬 저장소, 인증된 루프백 사람 검토 화면, 수동 설정하는 stdio를 구현했습니다. 로컬 합성 시험을 통과했으며 실제 데이터 사용·운영 인증·실제 ChatGPT/Codex 호스트 연동은 아직 지원하지 않습니다.
