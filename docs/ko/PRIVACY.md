# Context Ontology Companion — 개인정보

현재 프리뷰에는 합성 데이터만 사용합니다. 실제 대화·인증 정보·개인 기록·비공개 소스를 예제나 로그·이슈에 넣지 않습니다. 로컬 코어는 텔레메트리나 외부 모델 보강을 전제로 하지 않습니다. 호스트에 붙여 넣은 자료에는 호스트의 처리 규칙이 별도로 적용됩니다. 로컬 삭제로 호스트 기록·백업·기존 내보내기까지 지워진다고 보장하지 않습니다.

`demo`는 합성 예제·임시 저장소·모의 승인을 사용합니다. 별도의 로컬 프로토타입에는 영구 로컬 저장소, 인증된 루프백 사람 검토 화면, 수동 설정하는 stdio를 구현했습니다. 로컬 합성 시험을 통과했으며 실제 데이터 사용·운영 인증·실제 ChatGPT/Codex 호스트 연동은 아직 지원하지 않습니다.

[상세 정책(영어)](../../PRIVACY.md) · [문서 목차](README.md)

Proposal의 승인 유효기간은 15분이며, 만료가 자동 디스크 삭제를 뜻하지 않습니다. Payload 정리는 검토 서버 실행 중 30초마다, 또는 운영자가 `purge-expired`를 명시적으로 실행할 때 수행합니다. 변경 초안 준비는 이 정리를 수행하지 않습니다. 검토 서버와 정리 작업이 멈춰 있으면 만료된 payload는 정리가 실행될 때까지 디스크에 남습니다.
