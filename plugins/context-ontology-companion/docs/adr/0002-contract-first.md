# ADR-0002 — 계약 우선, 코어는 검증 후 추출

날짜: 2026-08-29

상태: **Proposed implementation of accepted direction**

## 배경

공유 인터페이스와 라이브러리까지 한 번에 분리하면 기존 제품을 불필요하게 재구성할 위험이 있습니다.

## 결정

초기 contracts 초안을 검토해 독립 버전으로 발행하고, 실행 코어는 실제 두 소비자가 확인된 뒤 추출합니다.

## 결과와 대안

초기에는 Context 저장소 안에서 계약을 incubate할 수 있습니다. 별도 공통 DB나 서비스는 만들지 않습니다.

## 변경 규칙

새 근거가 나오면 기존 문서를 지우지 말고 대체 ADR과 이유·영향·승인 상태를 기록합니다.
