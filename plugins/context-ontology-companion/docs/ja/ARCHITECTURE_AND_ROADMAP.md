# Context Ontology Companion — 構成とロードマップ

Contracts はバージョン付き成果物を共有し、各製品が自身のワークフローと権限を管理します。Context プレビューはローカル合成消費者、Contracts プレビューは決定的なオフライン検証器です。信頼できる承認ホスト、本番保存、公開プラグイン、任意の Code 連携は後続段階です。実際の二つの消費者が同じ要件を実証してから実行コアを抽出します。

`demo` は合成例、一時保存、模擬承認を使用します。別のローカル試作版には、永続ローカル保存、認証付きループバックの人による確認画面、手動設定する stdio を実装しました。ローカルの合成テストは成功しています。実データの利用、本番認証、実際の ChatGPT/Codex ホスト連携は未対応です。
