# Context Ontology Companion — プライバシー

現プレビューには合成データだけを使用します。実際の会話、認証情報、個人記録、非公開ソースを例・ログ・Issue に含めないでください。ローカルコアはテレメトリーや外部モデルによる補完を前提にしません。ホストへ貼り付けた情報にはそのホストの規則が適用されます。ローカル削除はホスト履歴・バックアップ・既存エクスポートの削除保証ではありません。

`demo` は合成例、一時保存、模擬承認を使用します。別のローカル試作版には、永続ローカル保存、認証付きループバックの人による確認画面、手動設定する stdio を実装しました。ローカルの合成テストは成功しています。実データの利用、本番認証、実際の ChatGPT/Codex ホスト連携は未対応です。

[詳細方針（英語）](../../PRIVACY.md) · [ドキュメント一覧](README.md)

Proposal の承認有効期間は15分で、期限切れはディスクからの自動削除ではありません。Payload の削除は確認サーバーの稼働中に30秒ごと、または運用者が `purge-expired` を明示的に実行したときに行います。変更案の準備はこの削除を行いません。サーバーと保守処理が停止している間、期限切れの payload は削除処理までディスクに残ります。
