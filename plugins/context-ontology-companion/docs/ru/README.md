`demo` использует синтетические примеры, временное хранилище и имитацию одобрения. Отдельный локальный прототип уже реализует постоянное локальное хранение, проверку человеком с аутентификацией через loopback и вручную настраиваемый stdio. Локальные синтетические тесты пройдены. Реальные данные, промышленная аутентификация и фактическая интеграция с ChatGPT/Codex пока не поддерживаются.

Code, Context и Contracts — независимые продукты. Потребители могут закреплять или включать контрактные артефакты без установки плагина Contracts. Это не означает общую БД, наследование прав, автоматический вызов другого плагина или изменение существующего Code.

Локальная проверка с аутентификацией и вручную настраиваемый stdio реализованы как предварительная версия; фактическая интеграция с хостом проверяется отдельно. Используйте только синтетические данные. Защита Windows ACL не проверена.
