# Context Ontology Companion — Безопасность

Успешная проверка схемы не разрешает действие. Сохраняйте область доступа, доказательства, ограничения ресурсов и явные неподдерживаемые результаты. Не публикуйте подробности уязвимостей и чувствительные входные данные в открытых задачах. В черновике не заявлены действующий закрытый канал сообщений или SLA; перед выпуском владелец должен создать и проверить реальный канал.

`demo` использует синтетические примеры, временное хранилище и имитацию одобрения. Отдельный локальный прототип уже реализует постоянное локальное хранение, проверку человеком с аутентификацией через loopback и вручную настраиваемый stdio. Локальные синтетические тесты пройдены. Реальные данные, промышленная аутентификация и фактическая интеграция с ChatGPT/Codex пока не поддерживаются.
