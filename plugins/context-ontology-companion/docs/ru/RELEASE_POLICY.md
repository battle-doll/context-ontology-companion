# Context Ontology Companion — Выпуск и откат

Отдельно отслеживайте проектирование, контракт, программу, интеграцию с хостом, подачу, одобрение и публикацию. Успех на одном компьютере не подтверждает выпуск для трёх ОС. Закрепляйте версии и digest, храните неизменяемые свидетельства выпуска. До публикации проверьте права на лицензирование, закрытые сообщения о безопасности, все заявленные ОС и реальный процесс хоста. Для отката кода нужен проверенный совместимый план данных и контрактов.

`demo` использует синтетические примеры, временное хранилище и имитацию одобрения. Отдельный локальный прототип уже реализует постоянное локальное хранение, проверку человеком с аутентификацией через loopback и вручную настраиваемый stdio. Локальные синтетические тесты пройдены. Реальные данные, промышленная аутентификация и фактическая интеграция с ChatGPT/Codex пока не поддерживаются.
