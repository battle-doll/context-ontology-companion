# 문맥 예산 참조 실험

이 폴더는 제품 구현이 아니라 합성 후보 그룹의 **필수 포함·충돌 원자성·근거 유지·직렬화 예산**을 시험합니다. 검색, 권한, 시점 선택, 삭제, 사용자 승인, DB, MCP, 실제 모델 호출은 구현하지 않습니다. 입력이 이미 허용됐다는 upstream 전제를 실제 보안 검증으로 오해하지 마세요.

```bash
python -m unittest discover -s experiments/tests -v
```

기본 단위는 UTF-8 byte입니다. 전체 JSON을 실제로 직렬화한 크기로 판정하며, token으로 환산하지 않습니다. custom counter는 실제 해당 단위 측정기가 있을 때만 사용합니다. 선택 순서는 필수 전체, 선택 그룹 우선순위·ID 순의 greedy 정책입니다. 최적 검색/최적 packing을 주장하지 않습니다.

필수 그룹이 안 들어가면 InsufficientBudget 내부 예외로 반환하며 성공 팩을 만들지 않습니다. 호출 계층에서 이를 사용자에게 어떻게 표시할지는 실제 제품에서 구현해야 합니다. 입력 객체는 읽기만 합니다. 후보가 모두 들어가도 전체 지식을 다 찾았다는 보장은 없습니다.
