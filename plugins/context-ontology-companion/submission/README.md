# 제출 경로와 과거 MCP 준비 자료

현재 최초 배포는 **skills-only ZIP** 경로이다. Skill과 필요한 로컬 실행 코드를 함께 제공하며, 현재 공개·제출·심사·게시 상태는 [release-state.json](../release-state.json)을 확인한다. 사용자의 공개 승인은 실제 제출 수락이나 Directory 게시 결과를 대신하지 않는다.

이 폴더의 기존 MCP 검토 자료는 **2026-09-05 로컬 구현 스냅샷**이다. 당시 상태 `LOCAL_IMPLEMENTATION_REVIEW_NOT_SUBMISSION_READY`는 호스팅된 MCP 경로에 대한 과거 판정이며, 현재 skills-only ZIP의 준비·제출 상태를 뜻하지 않는다.

[review-cases.draft.json](review-cases.draft.json)은 긍정 5개·부정 3개의 MCP 검토용 시나리오이며, [chatgpt-app-submission.json](../chatgpt-app-submission.json)은 당시 로컬 구현 8개 도구에 근거한 역사적 입력 초안이다. Hosted ChatGPT, 운영 MCP URL, OAuth/domain, 심사 근거를 검증한 제출 파일이 아니므로 현재 skills-only 제출물 대신 업로드하지 않는다. [구현 검토](IMPLEMENTATION_REVIEW.md) 역시 같은 과거 MCP 검토 문맥에서 읽는다.

향후 MCP를 포함하는 별도 제출은 [공개 등록 런북](../docs/09_PUBLIC_PLUGIN_SUBMISSION.md)에 따라 실제 hosted 구현·메타데이터·정책·계정 상태와 호스트 시험을 다시 검증한다. 로컬 Codex stdio 시험, skills-only 배포, hosted MCP 제출은 서로 다른 근거를 사용한다.
